# Mynote 视觉规范：笔记看板与导出一致性

## 设计目标

Mynote 的首页卡片不是供应链指标看板，而是个人笔记的可扫读入口。布局需要在手机竖屏保留熟悉的时间线胶囊；横屏手机、平板与桌面则提高同时可见的笔记数量。每张卡片仍代表一条完整笔记，标题、摘要、标签、日期与媒体内容都应能回到编辑器原文。

## 从 Supplykit 借鉴什么

Supplykit 的 [README 看板介绍](https://github.com/Overtrees/Supplykit-edgeone/blob/feat/edgeone/README.md)强调“一页尽览”、卡片与业务数据同源、信息会随渠道和模式切换。其[原始 UI 设计规范](https://github.com/Overtrees/Supplykit-edgeone/blob/feat/edgeone/docs/UI_DESIGN.md)把卡片按小/中/大分级，规定小卡正方形、网格对齐，并要求内边距按内容密度选择；对手机横屏，它明确反对单纯压小字号来换空间。

转化到 Mynote 后，适用的是“网格一致、卡片层级清楚、密度由内容而不是缩字解决、同一笔记数据同源”。Supplykit 的四列指标卡、告警色语义、数字降维阈值和其特定玻璃装饰属于供应链产品语境，不直接照搬；Mynote 使用三列笔记卡和自己的语义令牌，且卡片继续遵守无外投影、不提亮、不加辉光的产品偏好。

通用参考还包括 [Material Design 卡片指南](https://m3.material.io/components/cards/guidelines)关于一个容器围绕一个主题、标题/说明/媒体形成层级，以及 [Atlassian 网格基础](https://atlassian.design/foundations/grid)关于固定边距与间距、对齐和随视口调整的原则。

## 首页卡片规则

- **手机竖屏**：继续使用现有纵向胶囊列表，不改变原有时间线阅读习惯。
- **手机横屏**：视口高度不超过 560px 时切换到三列网格；宽度足以容纳三个卡片时避免窄横屏笔记继续挤成一列。时间分组标题跨满网格宽度，日期分组仍清晰可扫读。
- **平板与桌面**：视口宽度至少 768px 时使用三列网格；内容区最大宽度 1240px，左右留白 24px，卡片间距 14px。
- **几何**：每张笔记卡 1:1，圆角固定使用 `--radius-26`（26px）；不依靠外阴影或发光来分隔卡片。
- **正文卡**：标题优先，其次是摘要，日期与标签作为辅助信息；标题与摘要允许换行并限行，保留原字体尺度，不为横屏压缩字号。
- **图片卡**：同样占据正方形网格单元；图片封面按比例填充上部，底部信息区固定 78px，标题和摘要沿用语义字号与颜色令牌。
- **折叠多笔记**：分组中收起的多条笔记仍显示为一个可展开入口，并以无投影的错层卡片边界表达叠放；展开后各笔记独立进入网格。
- **标签与截断**：卡片标题优先，标签允许换行并限行；标签较多时保留前两项并显示剩余数量，图片卡在固定信息区内以单行摘要呈现。字号不因列数增加而缩小。
- **内容边界**：使用 `overflow-wrap` 与有限行数防止长 URL、连续字符或过长预览破坏网格；卡片仍指向完整笔记，不在首页截断或改写原始内容。

相应断点和尺寸实现位于 `src/styles/base.css`，26px 圆角令牌位于 `src/styles/tokens.css`。

## 导出一致性规则

HTML、PDF 和 Markdown 都从用户此刻正在编辑的 `.editor-body` DOM 与应用 CSS 样式表捕获快照，而不是为少数卡片类型手写近似替代视图。这样图文卡、图文横排、图片/画廊、附件、链接/音乐卡片、待办及编辑器渲染出来的其他块都沿用同一结构和样式。复选框导出时也会同步当前选中状态。

- **HTML**：输出完整独立文档，内嵌捕获到的应用样式和笔记 DOM。
- **PDF**：使用同一份 HTML 文档进入浏览器打印流程，不单独重画卡片。
- **页眉**：HTML 与 PDF 共用编辑器式页眉，含标题胶囊、当前笔记头像以及返回/更多图标；返回与更多为静态装饰，不把应用内编辑操作伪装成导出文件功能。打印时保留整套页眉，让 PDF 与 HTML 视觉一致。
- **Markdown**：文件保留 Markdown 扩展名与可解析的原始内容，并嵌入 `<style>` 与 HTML DOM 快照，以让支持原始 HTML/CSS 的 Markdown 阅读器尽量复现视觉。若阅读器主动删除 `<style>` 或限制 HTML，显示效果由阅读器策略决定；这是 Markdown 格式本身的互操作边界。缺少编辑器 DOM 快照时才回退到语义 Markdown。

## 编辑器大屏布局

- **平板与桌面**：可用宽度至少 768px 且高度至少 600px 时采用双栏书页式编辑；宽桌面在矮视口下也保留双栏，内容区最大宽度 1440px，以细分隔线表达书脊，不加卡片投影。
- **窄屏横屏**：宽度不足 1100px 且视口高度低于 600px 时保持单栏，优先保留可读行宽与输入空间；该判断刻意不把横屏手机也切成双栏。
- **媒体与编辑**：正文仍是单一 `contentEditable` DOM 流；图片、图文卡、画廊和音乐卡片跨双栏整行显示，原子卡片避免在栏间拆分。

## 主题与无障碍

所有颜色、字号和圆角继续通过 Mynote 的 CSS 令牌控制；深色模式与系统减少透明效果由现有语义变量和平台回退处理。系统开启“减少动态效果”时，页面动画和过渡立即缩短到近乎无动画，关闭回调不额外等待。链接保留安全协议过滤，快照内容沿用净化流程。网格规则不隐藏键盘焦点，不移除卡片原有操作，也不引入阴影、亮度提升或辉光装饰。

## 实现与验收

- 首页：`src/styles/base.css`、`src/styles/tokens.css`
- 编辑器双栏断点与媒体规则：`src/styles/editor-shell.css`
- 导出入口与头像传递：`src/app/editor.js`
- DOM/CSS 快照、导出页眉及回退：`src/app/editor/export.js`
- 回归测试：`tests/export.test.mjs`、`tests/tokens.test.mjs`
- 本轮验收：`npm test`、`npm run verify`
