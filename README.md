# 此刻

有时候你只是想记一句话、存一张图、贴一个链接。  
不想先建目录，不想被一堆按钮打断，也不想为了记点东西先登录账号。  
「此刻」就是为这种场景做的：打开就写，离线也能用。

---

## 2.0.2 这次做了什么

这版主要是把体验里的“小别扭”磨掉：

- 编辑页返回首页的过渡顺滑了很多，闪烁明显减少
- Google 登录/退出后，首页头像自动同步，不用手动刷新
- 天气链路修好了（和风主用，彩云兜底）
- 启动页恐龙换成了 SVG，视觉更统一
- 备份页图标、Toast 显示细节修复
- 浅色背景改成 iOS 系统灰 `#f2f2f7`，看着更舒服

## 这个 App 想解决什么问题

不是做一个“最强笔记系统”，而是做一个你愿意每天顺手打开的记录工具。

你会在这些时刻用到它：

- 地铁上突然想到一个点子，想马上记下
- 刷到一首歌，想留个卡片以后再听
- 记会议要点、待办、灵感碎片，不想切来切去
- 没网的时候也希望能照常写

---

## 日常会用到的功能

### 记
- 段落、标题、待办、引用、分割线
- 图文卡片、图片卡片、音乐卡片
- Markdown 自动渲染（表格、代码块、Callout 等）

### 看
- 首页按时间分组，信息一眼就能找到
- 支持置顶、展开/收起
- 图文预览会自动适配

### 存
- 默认本地保存（离线可用）
- 支持 Google Drive 云备份
- 支持 ZIP 导出/导入（含附件）

### 调
- 字号切换
- 笔记背景色
- 头像（含 Google 头像同步）

---

## 和常见笔记工具不一样的地方

- 不强调“组织体系”，强调“打开就能记”
- 不强绑定账号，默认本地优先
- 不追求花哨功能，优先把写和看做好
- 更重视 iOS 观感细节（安全区、毛玻璃、过渡、圆角）

## 隐私

- 没有第三方追踪和统计
- 数据默认在你本地浏览器
- 只有你主动点备份时，才会上传到你的 Google Drive

---

## 技术说明（简短）

技术上不炫技，够稳、够快、够省心就好：

- React 18（UMD）
- IndexedDB + localStorage
- Cloudflare Worker（链接抓取）
- 依赖本地化，无运行时 CDN
