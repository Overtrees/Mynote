# 此刻

有时候你只是想记一句话、存一张图、贴一个链接。  
不想先建目录，不想被一堆按钮打断，也不想为了记点东西先登录账号。  
「此刻」就是为这种场景做的：打开就写，离线也能用。

---


## 这个 App 想解决什么问题

不是做一个“最强笔记系统”，而是做一个你愿意每天顺手打开的记录工具。

你会在这些时刻用到它：

- 地铁上突然想到一个点子，想马上记下
- 刷到一首歌，想留个卡片以后再听
- 记会议要点、待办、灵感碎片，不想切来切去
- 没网的时候也希望能照常写

---

## 日常会用到的功能

### 记
- 段落、标题、待办、引用、分割线
- 图文卡片、图片卡片、音乐卡片
- 标题胶囊（原地编辑，滚动自动切换横竖排）
- 斜杠命令面板（支持搜索筛选、最近使用）
- Markdown 自动渲染（表格、代码块、Callout 等）

### 看
- 首页按时间分组，信息一眼就能找到
- 支持置顶、展开/收起
- 图文预览会自动适配
- 编辑页切入切出过渡动画（滑入滑出 + 首页跟随）

### 存
- 默认本地保存（离线可用，IndexedDB 主存储）
- 支持 Google Drive 云备份（含附件）
- 支持本地 ZIP 导出/导入
- 云端恢复（合并云端与本地数据）
- 最近操作记录（备份、恢复、导出、登录历史）

### 调
- 字号切换
- 笔记背景色（8 色，含自适应顶部渐变）
- 头像（含 Google 头像同步）

---

## 和常见笔记工具不一样的地方

- 不强调“组织体系”，强调“打开就能记”
- 不强绑定账号，默认本地优先
- 不追求花哨功能，优先把写和看做好
- 更重视 iOS 观感细节（安全区、毛玻璃、过渡、圆角）

## 隐私

- 没有第三方追踪和统计
- 数据默认在你本地浏览器
- 只有你主动点备份时，才会上传到你的 Google Drive

## 技术说明（简短）

技术上不炫技，够稳、够快、够省心就好：

- React 18（UMD）
- IndexedDB + localStorage
- Cloudflare Worker（链接抓取）
- 依赖本地化，无运行时 CDN
